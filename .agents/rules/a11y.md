# Accessibility baseline

Every component and page:

- Works with the keyboard alone, with a logical tab order and visible focus.
- Uses semantic HTML: landmarks, one `h1`, ordered headings, `<button>` for actions and `<a>` for navigation.
- Manages focus correctly for dialogs and popovers (move it in, trap it where appropriate, return it on close).
- Gives images meaningful `alt` text (or `alt=""` when they're decorative).
- Respects `prefers-reduced-motion`.

Done well this is invisible, so it never conflicts with cloning the OG look. When it does change the look, list it in
the PR.
